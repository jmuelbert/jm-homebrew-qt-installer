Welcome to **jm-homebrew-qt-installer** — a Homebrew formula and collection of helper tools for installing and testing
the Qt Installer Framework (QtIFW). The project is designed for CI-ready, versioned, and reproducible installer builds.

## What You Can Do

<CardGrid>
  <Card title="Install QtIFW" icon="seti:homebrew">
    Use the Homebrew formula to install a versioned Qt Installer Framework in your development
    environment or CI pipeline.
  </Card>
  <Card title="Test Your Setup" icon="approve-check">
    Use the included helper tools to check your installation and support reliable installer builds.
  </Card>
  <Card title="Build Reproducibly" icon="seti:github">
    Keep QtIFW versions consistent across machines and CI runs for more predictable results.
  </Card>
</CardGrid>

## Getting Started

1. **Install the formula:** Follow the installation instructions in the project’s README.
2. **Check your setup:** Run the documented helper tools to verify that QtIFW is available.
3. **Use it in your build:** Add the installation steps to your local workflow or CI pipeline, and pin the QtIFW version
4. used by your project.
